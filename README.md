# Gerenciador de Arquivos e Diretórios

Um programa simples de gerenciamento de arquivos e diretórios desenvolvido em Python para execução pelo terminal.

O projeto permite ao usuário criar diretórios, criar arquivos e excluir arquivos através de um menu interativo.

## Funcionalidades

Atualmente, o programa possui as seguintes funcionalidades:

- Criar diretórios;
- Criar arquivos no diretório atual;
- Criar arquivos dentro de diretórios existentes;
- Listar diretórios disponíveis;
- Listar arquivos disponíveis para exclusão;
- Excluir arquivos;
- Validação básica das opções fornecidas pelo usuário;
- Tratamento de erros relacionados à criação de diretórios já existentes.

A opção de leitura de arquivos está presente no menu, mas ainda está em desenvolvimento.

## Tecnologias utilizadas

- **Python 3**
- **Módulo `os`** — utilizado para manipulação de arquivos e diretórios.
